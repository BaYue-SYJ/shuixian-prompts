## 二、功能清单与用法

### 1. 变量填空 → 复制成品
你的提示词里大量使用 `{argument name="X" default="Y"}` 占位符。
现在点「✍️ 填变量并复制」会弹出表单：把每个变量填好，**实时预览**里填进去的部分高亮显示，留空的回落到默认值；点「复制成品」拿到的是**能直接用的文本**，不再是带占位符的模板。同时保留「复制模板」。

支持三种写法：`{argument name="x" default="y"}`、`{{var}}`、`[VAR]`。

### 2. 标签分面（在 79 个分类之外再加一层）
从每条提示词的标题／分类／正文里自动提取三类**横切标签**：
- **媒介**：海报 / 信息图 / 插画 / 摄影 / 3D渲染 / UI界面 / Logo图标 / 字体排版 / 包装设计 / 漫画分镜 / 卡牌 / 封面
- **风格**：极简 / 赛博朋克 / 复古 / 国风 / 日系 / 电影感 / 杂志风 / 手绘 / 像素 / 构成主义 / 故障艺术 / 蒸汽朋克 / 哥特 / 可爱 / 写实 / 奇幻
- **色调**：黑白 / 高饱和 / 低饱和 / 暖色 / 冷色 / 黑金 / 粉紫 / 绿色系

画廊页与搜索页顶部出现分面栏，带实时计数，可多选（同一类内取或，跨类取与）；点「+N 更多」展开全部。卡片上也会显示前 3 个标签。

### 3. 智能搜索
- **模糊匹配**：不要求连续，`海报设计` 能命中「设计感海报」之类
- **拼音首字母**：输入 `sbpk` 就出「赛博朋克」；中英混排也行
- **关键词高亮**：结果里命中的词用 `<mark>` 标出（已做 HTML 转义）
- **相关度排序**：搜索后排序多一个「相关度」选项，标题命中优先于正文命中

### 4. 命令面板 `Ctrl / ⌘ + K`
一个输入框同时搜「功能 + 分类 + 提示词」：可直接跳页、随机漫游、切主题、切语言、导出合集；也能直接搜到某条提示词并按回车打开。↑↓ 移动，Enter 打开。

### 5. 收藏合集（收藏页已重写成管理器）
- 多合集：新建 / 重命名（双击合集标签也可）/ 复制 / 删除 / 清空
- **拖拽排序**：合集标签可拖动调序；合集内卡片可拖动调序
- **跨合集移动**：卡片右上角「移动到…」，可移入已有合集，也可「新建合集并移入」
- **导出**：Markdown / JSON / CSV（带 BOM，Excel 直接打开不乱码），或一键复制全部提示词；也可「导出全部」合并所有合集
- **导入**：自己的 JSON 可以再导回来（条目会以 `imp-` 前缀另存，不污染原库）
- 合集、备注、「用过」标记都只存在**本机浏览器**，无需登录

### 6. 图片下载
灯箱与卡片右上角都有下载按钮（走 fetch→blob，文件名自动用标题+ID）；收藏页支持「批量下载图片」（顺序下载、带进度提示）。

### 7. 备注 / 使用次数
灯箱与详情页底部有备注框（边打边存），卡片右上角有黄点表示「这条有备注」；「标记已用」会累加使用次数，可按「只看有备注 / 仅看用过的」筛选。

### 8. 筛选器
画廊 / 搜索页工具栏新增：只看有图、只看有备注、仅看已收藏、仅看用过的。

### 9. 其它
- **随机漫游**：右下角 🎲 浮动按钮，或按 `R`；画廊排序也有「随机」
- **深链分享**：`#id=12345` 直达某条并自动打开灯箱；灯箱里「🔗 复制链接」
- **灯箱翻页**：‹ › 按钮或 ←/→，按上下文（当前筛选结果）翻，不是全库乱跳
- **LQIP 加载**：图片先模糊后清晰，避免大片空白
- **中英切换（真正的英文版）**：顶栏 `EN / 中`。点一下**整站换语言**——导航、页头、按钮、空状态、筛选器、合集管理、命令面板、快捷键帮助、**以及 87 个分类名**全部翻译；选择会记住，下次打开仍是英文。详见第 13 节。
- **PWA**：可「安装到桌面」，离线可浏览外壳与轻量数据
- **快捷键**：`?` 看全部

### 10. 油猴侧边栏
`userscript/shuixian-prompt-garden.user.js`：装到 Tampermonkey 后，在 ChatGPT / Claude / Gemini / Midjourney / 即梦 / DeepSeek 页面按 `Ctrl+Shift+K` 召唤侧边栏，搜索→（有变量则填表单）→ 一键复制到剪贴板。
**用前把脚本顶部的 `SITE` 改成你的线上地址**（如 `https://xxx.pages.dev`）。

### 11. 导航栏改版（本轮，最终形态）
**问题**：先是把「命令面板」做成 `.nav-actions` 里的独立按钮 → 导航总宽超标（~1080px 下约需 1312px），右侧「经典版/主题/收藏/投稿」被挤出视口，切英文后链接被压成竖排；改成塞进搜索框的 `⌘K` 角标后，又受浏览器缩放/英文长文案影响，角标时有时无。

**最终做法（按需求执行）**：
- **导航里的搜索框整体删除**（`components/header.html` 移除 `.nav-search`）。搜索本来就能在命令面板里做，等于二合一，同时一举释放约 300px 宽度。
- 导航右侧改为**一个显式的「命令面板 ⌘K」按钮**（`js/features.js` 动态注入 `.nav-actions` 首位）。
- 导航链接 `white-space:nowrap` + `flex:none`，永不换行/被压缩；`.nav-actions{margin-left:auto}` 稳定靠右。
- 逐档收紧：≤1366 缩间距 → ≤1280 缩链接内边距 → ≤1200 隐品牌副标题 → ≤1120 隐「命令面板」文字保留图标+⌘K → ≤1040 隐语言按钮（命令面板内仍有「切换语言」）→ ≤920 隐 ⌘K → ≤1000 收成汉堡菜单（原为 860，太晚）。
- ≤1000px 时菜单里也有「命令面板」入口；`/` 键若无搜索框则直接唤起命令面板。
- 页面内的搜索（画廊工具栏「在结果里搜索」、搜索页大搜索框）**保持不变**。

> 注：`.kbd-chip` 样式与 `.nav-search` 覆盖规则已随之移除；`gallery.html` 工具栏复用 `.nav-search` 类做搜索框，不受影响。

### 12. 移动端菜单 + 语言（本轮）
**问题 A —— 移动端菜单项居中**：`base.css` 的 `.nav-links` 带 `align-items:center`（桌面横排时是对的），但 ≤1000px 展开为纵向列后，`align-items` 沿横轴生效，把每一项都水平居中了。
修法：`features.css` 里给 `.nav-links.open` 加 `align-items:stretch`，并让菜单项 `width:100%; text-align:left`；同时给菜单加 `max-height:calc(100vh - var(--nav-h)); overflow:auto` 防止条目多时溢出屏幕。超小屏（≤420）工具按钮跟着 `.icon-btn` 一起收紧到 38px。

**问题 B —— 语言切换造成"半中文半英文"**：`EN` 只翻译了导航链接和「投稿」，页面正文/分类名仍是中文；而且动态生成的按钮（如移动端菜单里的「命令面板」）**不会跟着刷新**，于是出现「导航是英文、按钮是中文」的矛盾状态。
修法：**先整体下线**（`ENABLE_LANG_SWITCH = false`，并清掉 localStorage 里遗留的 `sx-lang`，避免导航被卡在英文无法切回），随后**重做成真正的英文版**——见第 13 节。现在语言切换整站生效，不会再出现半翻译。

### 13. 真正的英文版（本轮新增）
顶栏 `EN / 中` 一点，**整站换语言**。

**覆盖范围（261 组文案 + 87 个分类名）**
- 全站 chrome：导航、页头（eyebrow / 标题 / 副标题）、按钮、空状态、页脚、文档标题
- 功能层：命令面板、变量填空、标签分面、筛选器、合集管理、导出菜单、灯箱与详情、快捷键帮助、各种 toast 提示
- **92 个分类名**（13 大类 + 79 小类）：`人物写真 → Portraits`、`随手拍 → Snapshots`、`9宫格 → 9-Grid`、`构成主义 → Constructivism` …
- 五个内容页（关于 / 赞赏 / 投稿 / 分类 / 404）正文全部翻译
- **不变的部分**：5430 条提示词正文与其标题保持中文（那是内容本身）；分类的 `?cat=` 参数与数据结构保持中文原名，只有**显示**走翻译

**实现方式**
1. `js/i18n.js` 单一字典源：`ui.zh` / `ui.en`（可含少量 `<b>` 等标记）+ `cat`（分类名映射）。
2. `features.js` 的 `applyI18n()` 处理三种标记：`data-i18n`（替换 innerHTML）、`data-i18n-placeholder`、`data-i18n-title`；并同步 `document.title`、`<html lang>`、以及 JS 动态生成的按钮（命令面板 / 语言按钮 / 版本切换）。
3. 带数字的文案用 `{total}` `{n}` `{q}` 占位，由 `FX.tf(key, {...})` 从实时数据补值（如首页导语、分类总览副标题、搜索命中数）。
4. `base.js` 增加 `T() / TF() / catLabel()` 三个钩子——未加载 features.js 时自动回落中文，因此**经典版不受影响**。
5. 页面里的动态文案（画廊计数与图例、搜索计数与图例、分类总览、详情页按钮、收藏页全部提示）全部改为调用 `FX.t / FX.tf / FX.catName`。

**为什么切换是"重载页面"而不是就地替换**：卡片、分类名、筛选器、合集都是按语言渲染的，就地替换必然漏掉一部分（这正是之前"导航英文、按钮中文"的成因）。重载保证 100% 一致，数据已缓存所以很快。

**新增维护脚本**
```bash
python tools/inject_i18n.py     # 新增页面/文案后，批量补 data-i18n 标记（幂等）
node  tools/test_i18n.js        # 校验：页面 key 是否都在 zh/en、分类英文是否齐全、zh/en 是否对齐
```

> 经典版（`classic/`）仍是纯中文——它有独立的模板与文案体系，要英文化需另做一套。需要的话说一声。

## 三、经典版（classic/）本轮新增

经典版有自己一套 `classic/js/base.js`（数据加载、标签体系、收藏画板都与现代版不同），所以新功能是**独立实现**的，不共用 `features.js`。

| 功能 | 说明 |
|---|---|
| **命令面板** `Ctrl/⌘+K` | 顶栏新增 `⌘K` 按钮（窄屏只显示 ⌘K）；可搜提示词 / 分类 / 功能命令，↑↓ 选、Enter 开 |
| **智能搜索** | 模糊匹配 + **拼音首字母**（`sbpk` → 赛博朋克）+ 关键词高亮 |
| **变量填空复制** | 灯箱内「✍️ 填变量并复制」：表单 + 实时预览 → 成品 |
| **灯箱增强** | 备注框（边打边存）、使用次数、「标记已用」、下载图片、复制 Markdown，并显示命中标签 |
| **随机漫游** | 右下角 🎲 浮球，或按 `R` |
| **快捷键帮助** | 按 `?` |
| **图片 LQIP** | 图片先模糊后清晰 |

备注与使用次数和现代版**共用同一份 localStorage key**（`sx-notes-v1` / `sx-uses-v1`），两版之间互通。

> 经典版的分类色板、主题/风格标签、收藏画板是它原有体系，本轮未改动；分面筛选与合集管理仍只属于现代版（经典版本就有标签筛选）。

## 四、维护

```bash
# 数据更新后重建拼音表（否则新增汉字搜不到）
python tools/build_pinyin.py

# 新增页面 / 新文案后，补 data-i18n 标记（幂等，可反复跑）
python tools/inject_i18n.py

# 跑回归自测
node tools/test_features.js     # 功能逻辑（30 项断言）
node tools/test_i18n.js         # i18n 一致性（key 对齐 / 分类英文覆盖）
```

**改了静态资源记得同步升版本号**：4 个位置要一致 ——
`js/base.js` 的 `ASSET_VERSION`、各 HTML 的 `?v=`、`sw.js` 的 `VERSION` 与 `PRECACHE` 里的 `?v=`。
（部署到 CF Pages 后仍需按老规矩 **Purge Cache**，JSON 数据不带 `?v=`。）

`_headers` 里已加 `/data/* → Access-Control-Allow-Origin: *`，这是油猴脚本与第三方工具能跨域读数据的前提；`/sw.js` 设为 `no-cache`，避免 Service Worker 更新发不出去。

## 五、本轮**没有**做的（需要后端，非纯静态能完成）

| 功能 | 卡在哪 |
|---|---|
| 语义搜索（一句话找图） | 需要向量模型或预计算 embedding + 检索服务 |
| 站内 AI 一键生图 | 需要把中转站密钥放在服务端，不能进静态站 |
| 图片→反推提示词 | 需要视觉模型调用 |
| 社区（投稿、点赞、评论、排行） | 需要数据库与鉴权 |

> 英文版已完成（见第 13 节）；**经典版 `classic/` 仍是纯中文**，如需英文化需再排一套。

这几项等你决定要不要上后端（可走 Cloudflare Workers + KV/D1）再单独做。
